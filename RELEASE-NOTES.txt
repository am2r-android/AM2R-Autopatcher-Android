AM2R Autopatcher 1.5.5.11

Builds the Standard or Dual Screen ARM64 Android edition from your own original
AM2R 1.1 Windows ZIP. The installed game runs independently of the autopatcher.

Changes since 1.5.5.10 Hotfix 1
- Standard: touch controls are sampled before the gameplay input update, avoiding
  the extra simulation-step delay. Physical-controller handling is preserved.
- Dual Screen: HUD Style offers Large or Minimal for the lower screen. Large
  is the default for new settings; existing choices are preserved. Large uses
  separate health and ammo rows, tall blue energy bars, remaining ammo grouped
  on the left, and the area title on the right. Metroid counters sit above the
  area title with matching panel edges; completion percentage sits at the far
  right of the timer strip. Minimal remains available, and HUD Style is disabled
  when HUD Screen Position is Top Screen.
  One bottom toolbar shows + / - / 1x / Fit Map / Follow during play, and
  Marker / Menu / Unpause on the paused map. All four profile layouts are updated.
- Dual Screen: adds the Mining Facility map title and drill-chamber background.
- Dual Screen: uses the dedicated Dual-Screen controller recommendation
  artwork. Standard keeps its original controller recommendation screen.
- Both games: updated launcher artwork and adaptive icons, clearer application
  names, and Android game-category declarations. Existing package IDs and signing
  compatibility are retained. Game version code increases to 1005006.
- Both games: optional shared-folder save synchronization through Options → Data.
  Checks run before file selection and after saving. Conflicting changes are held
  for review and recovery copies are retained. Configure a separate file-sync
  app to transfer the folder; see SAVE-SYNC.txt. Manual Backup / Restore remains.
- Autopatcher: Android installation results are shown directly. Failed installs
  create a local diagnostic file labeled "share this to github issues page",
  with a Share action. Nothing is uploaded automatically. Cancellation is reported
  separately, and the generated APK remains available in Downloads.
- Autopatcher: native patch-library alignment and APK compatibility diagnostics
  improve support and troubleshooting on newer Android devices.
- Source: shared game metadata and independent artwork-export helpers are included.
  Cocoon supports manual title/artwork editing; automatic custom-metadata import
  has not been confirmed. Artwork payloads remain outside the code-only archives.

Updates and compatibility
Install over the existing edition to retain its private saves. Do not uninstall
first. Standard and Dual Screen remain separate apps with separate save storage;
use the existing Data backup/restore tools to transfer progress.

AYN Thor has physical test coverage. RG DS, Retroid Pocket Duo / Duo Lite and
AYANEO Pocket DS profiles still await physical validation. The pinned game runtime
has a remaining native 16 KB alignment limitation, so installation on every
16 KB-page device is not guaranteed. Include the new installer report when an
installation fails. Syncthing transfers passed between two isolated Android
emulators and a Linux PC, including conflict handling. Desktop import/export
remains manual. Physical-device sync, Windows/macOS and other services still
need feedback; no network service is built into the game.
