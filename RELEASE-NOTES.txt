AM2R Android — 1.5.5.14 (Full Release)

Touch-control adjustment and Retroid Dual Screen Add-on support.

Standard Edition
- New Diagonal Aim Size slider adjusts diagonal aim arrows and the joystick
  within the same control area. Overall control scale and spacing stay separate.
- Touch targets follow the visible controls, and the controls menu now scrolls
  far enough to show Done.

Dual Screen Edition
- New Dual Screen Add-on option in the Retroid Pocket Duo / Duo Lite profile.
  Enable it for Retroid Pocket Nova with the Retroid Dual Screen Add-on: gameplay
  uses the external 16:9 panel, with the map and menus on the handheld.
- Gameplay fits the external panel correctly when the two displays have different
  aspect ratios. Nova add-on operation is confirmed through community testing.
- The option defaults off for ordinary Duo/Duo Lite setups. RG DS keeps its
  separate screen-order setting, and existing preferences are preserved.

Includes the fixes, translations and Nano improvements from 1.5.5.13.

Updating
Install the new Autopatcher, select your original AM2R_11.zip and rebuild the
edition you use. Install the generated APK over your existing game. Updating
only the Autopatcher does not update an already installed game.
Package IDs and signing are unchanged. Back up your saves before updating and
do not uninstall the game. Standard and Dual Screen remain separate applications.
Both game packages use version code 1005014; the Autopatcher uses version code 18.
The title-screen content version remains V1.5.5.
