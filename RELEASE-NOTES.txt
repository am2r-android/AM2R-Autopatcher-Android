# AM2R Android — 1.5.5.10 Hotfix 1

This hotfix updates the Dual Screen edition:

- Restores the reactor core temperature bar exclusively on the upper screen.
- Removes the lower screen's 30 fps update cap for smoother map panning,
  log scrolling and menus.
- Adds **Display Options → HUD Screen Position**. Keep health and ammunition
  below, or move them to the original upper HUD. The map, timer, completion
  percentage and Metroid counts remain below. The choice is saved.
- Restores upper-screen area-arrival titles and preserves the HUD while paused.

**Standard is unchanged.** Its touch-input latency fix is deferred.
Tested on AYN Thor; RG DS, Retroid Pocket Duo / Duo Lite and AYANEO Pocket DS
remain unconfirmed on physical hardware.

To update, install the new autopatcher, choose Dual Screen, patch your original
AM2R 1.1 Windows ZIP again, then install the generated APK over your existing
game. Back up first; do not uninstall the game. Updating the autopatcher alone
does not update an installed game. Standard users do not need to repatch.

The release includes the autopatcher APK, three code-only source ZIPs and
SHA256SUMS. Source media and signing files are excluded; original code licenses
and attribution are retained. No complete game APK is distributed.
