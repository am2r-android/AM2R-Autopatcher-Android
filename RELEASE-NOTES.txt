Water crash fixed in Standard and Dual Screen.

Fixed
- Fixed an error when water appears on screen, with Nano enabled or disabled.

Includes the features from 1.5.5.13 Beta.

Updating
Install the new Autopatcher, select your original AM2R_11.zip and rebuild the
edition you use. Install the generated APK over your existing game. Updating
the Autopatcher alone does not replace an already installed game.

Package IDs and signing are unchanged. Back up your saves before updating and
do not uninstall the game. Standard and Dual Screen remain separate applications.
Both game packages use version code 1005012; the Autopatcher uses version code 16.
The title-screen content version remains V1.5.5.
