AM2R Android — 1.5.5.13

Nano refinements, translations and lower-screen HUD improvements.

Both editions
- Translated the new Android settings and repaired menu layouts across the
  existing language selection, using the original community fonts. (new android and dual screen features were added using a translator)
- Long help text stays within the original menu strip and scrolls when needed.
- Nano reduces decorative pipe bubbles and pauses distant crabs; nearby combat
  remains active. The darkest Industrial Complex breeding grounds stay visible.
- Reduced unnecessary work around burrowing enemies and the reactor escape.
- Includes the water crash fix and the gallery fixes from earlier updates.
- Corrected the post-reactor Energy Tank map marker; affected saves repair it
  when re-entering the room.
- Extra modes start locked on fresh profiles again. Earned progress and the
  existing secret unlock code are preserved.

Standard Edition
- Native 3:2 joins 4:3 and 16:9 without stretching the artwork.
- Retains touch-control spacing/scale sliders and orientation options.

Dual Screen Edition
- Localized lower-screen actions and area titles, with corrected fonts, timer
  punctuation, controller hints and compact 4:3 HUD spacing.
- Mining Facility breeding grounds now show their discovered title and artwork.
- Retains RG DS screen-order setup and Nano enabled on first-time RG DS setup.
  Existing preferences are preserved when updating.

Updating
Install the new Autopatcher, select your original AM2R_11.zip and rebuild the
edition you use. Install the generated APK over your existing game. Updating
the Autopatcher alone does not replace an already installed game.

Package IDs and signing are unchanged. Back up your saves before updating and
do not uninstall the game. Standard and Dual Screen remain separate applications.
Both game packages use version code 1005013; the Autopatcher uses version code 17.
The title-screen content version remains V1.5.5.
