AM2R Autopatcher 1.5.5.11 — Hotfix 1

Standard Edition
- Fixed touch controls being unable to select Super Missiles with weapon style
  set to Hold. A Weapon Select button appears above Arm when both missile types
  are available. Hold Arm and tap Weapon Select to switch missile types.
- Toggle mode, physical controller controls and the earlier touch-timing
  improvement keep their existing behavior.

Dual Screen Edition
- Retains the final public 1.5.5.11 gameplay, HUD and menu behavior.

Updating
Repatch your original AM2R 1.1 Windows ZIP and install over your existing edition.
Package IDs and signing are unchanged; game saves and settings are retained.
Do not uninstall the game first. Both game packages use version code 1005007;
the Autopatcher uses version code 11. All other 1.5.5.11 features remain included.

Downloads
The Autopatcher APK, three media-pruned source archives and SHA256SUMS are
included. Complete playable game APKs are not distributed. Source licenses and
build limitations remain documented in each archive.
